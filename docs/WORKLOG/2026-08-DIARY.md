### Fix pthread_cancel Segfault on Linux GameSpy Threads
- Fixed `FATAL: exception not rethrown` occurring during GameSpy timeout aborts on Linux. `pthread_cancel` throws `abi::__forced_unwind` which was being swallowed by `catch (...)` in all GameSpy network threads (`PeerThread`, `BuddyThread`, `GameResultsThread`, `PersistentStorageThread`, `PingThread`).
- Added `#include <cxxabi.h>` and explicitly re-throw `abi::__forced_unwind` in those threads.
